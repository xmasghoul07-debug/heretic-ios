# Heretic AI - Web Browser Version

A fully browser-based interactive mockup of the Heretic AI iPhone app.

## How to run

1. Simply open `index.html` in any modern web browser
2. No dependencies or build process required
3. Works on desktop, tablet, and mobile browsers

## Features

- iPhone 13 mockup with rounded bezel and notch
- Dark mode GitHub-style design
- Fully scrollable content
- Interactive file selection
- Responsive design
- Smooth animations and transitions

## Files

- `index.html` - Main structure and markup
- `styles.css` - Complete styling for iPhone mockup and content
- `script.js` - Interactive features and animations

## Browser support

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Mobile browsers (iOS Safari, Chrome Mobile)
